After completing the initial product/category admin structure, prepare the system for phase 2 product importing workflow.

The admin should be able to input products ONE ITEM AT A TIME.

Workflow structure:

1. Admin selects:

* Main Category
* Sub Category

2. Admin inputs:

* Product name
* Product detail page URL

3. The AI system analyzes the provided link and automatically generates:

* Product images
* Product features
* Product description
* Material information
* SEO-friendly summary

4. The system should automatically:

* Download all product images
* Store images internally
* Convert images to WEBP
* Create thumbnails
* Generate a draft product entry

5. The generated draft should appear inside the admin editor before publishing.

---

## IMPORTANT WORKFLOW RULE

The system should NOT bulk import products automatically.

The workflow is designed for:

* Manual one-by-one product registration
* Careful admin review
* OEM/B2B product optimization

---

## IMPORTANT IMAGE STORAGE RULE

Never use external manufacturer image URLs directly.

The system must:

* Save images internally
* Optimize images for web
* Prevent broken images if source URLs change

Create a modern AI-powered B2B OEM/ODM product management system for a Korean beauty and hygiene manufacturing company.

The platform should focus on:

* Simple product catalog management
* AI-assisted product importing
* OEM inquiry conversion
* Request a Quote workflow

The system is NOT a normal e-commerce store.
It should function as a professional B2B OEM supplier catalog.

---

1. Cotton Pads

   * Round Cotton Pad
   * Square Cotton Pad

2. Wet Wipes

   * Biodegradable Wipes

3. Feminine Wipes

   * 15 Sheets

## PRODUCT IMPORT SYSTEM

Admins will input ONE product detail page URL at a time.

The system should:

1. Analyze the product page
2. Extract product information
3. Generate a draft product
4. Store images internally
5. Allow admin editing
6. Publish product

Supported source websites:

* Manufacturer websites
* Alibaba
* Amazon
* OEM supplier pages
* Brand websites

---

## IMPORTANT IMAGE RULE

NEVER hotlink external manufacturer images.

The system must:

* Download all images immediately
* Store images internally
* Convert images to WEBP
* Generate thumbnails
* Optimize image sizes
* Prevent dependency on external image URLs

---

## ONLY REQUIRED PRODUCT FIELDS

Each product should only include:

* Product name
* Product images
* Main category
* Sub category
* Features
* Product descriptions
* Material

DO NOT require:

* MOQ
* Lead time
* Certifications
* Packaging details
* Size
* Ingredients
* Sheet count
* OEM specifications
* Pricing

Those details should be handled through:
"Request a Quote"

## REQUEST A QUOTE SYSTEM

Every product page must prominently include:

* Request a Quote button
* OEM Inquiry button

Inquiry form fields:

* Company name
* Buyer name
* Email
* Country
* WhatsApp
* Product interest
* Quantity
* Customization request
* Message

The inquiry system should be the main conversion goal of the website.
